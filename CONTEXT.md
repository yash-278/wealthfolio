# Wealthfolio

## Quick Add

**Quick Add**: The flow for turning pasted transaction text into categorized
transactions. The application and an iPhone Shortcut are two entry points to the
same flow.

**Capture**: A submission of text for Quick Add to interpret. A capture is not
itself a posted transaction.

**Transaction**: A financial event recorded in an account, represented by an
activity in Wealthfolio.

**Review**: The user's resolution of an outstanding capture issue. A review may
concern an unposted candidate or categorization of an already-posted
transaction; review does not necessarily mean the transaction is absent.

**Candidate transaction**: A financial event identified in submitted text that
has not yet been confirmed as a saved transaction or an existing duplicate.

**Review item**: An unresolved issue linked to a capture and, when already
saved, its transaction. Resolving a category-review item changes the existing
transaction's classification without adding another transaction.
